一位患者，两次检查，三个实例

以下是虚构教学例子，不是实测源记录。P-DEMO 在 E-DEMO 就诊中做了两次检查：S-01 的 CT 序列有两个实例，S-02 的 MR 序列有一个实例。

患者 P-DEMO
└─ 就诊 E-DEMO
   ├─ 检查 S-01 → 序列 SE-01（CT）→ I-01、I-02
   └─ 检查 S-02 → 序列 SE-02（MR）→ I-03
1 位患者 · 1 次就诊 · 2 次检查 · 2 个序列 · 3 个实例

把患者 JOIN 到实例会得到三行，这是一对多展开。此时 COUNT(*) 是实例展开行数，不能当患者数或检查数。

01 / 读入：先明确每一行代表什么

源表业务唯一键关联
patientsId一位患者
encountersIdPATIENT 指向患者
imaging_studiesINSTANCE_UIDId 是检查标识；SERIES_UID 是序列；PATIENT / ENCOUNTER 是父级

不能用影像 Id 去重删除 I-02：它与 I-01 属于同一检查，却是不同实例。CSV 缺必要列、重复列名或行宽错误时整批失败。带引号换行是一条逻辑记录，不能按文本物理行编号。

02 / ODS：保留原始字段和回查入口

三张原始表均保留全字段字符串，包括空字符串。来源清单保存文件哈希等信息；处置账本和模型血缘使用 source_sha256 / source_row。旧 JSON 的记录顺序表达源行位置，Spark ODS 显式存储 source_row + raw map。

例子进入 ODS 后仍是 1 位患者、1 次就诊、3 个实例。这里不按检查粒度折叠。Parquet 分区读出的第一行不一定是源文件第一条记录，消费时必须沿用保存的 source_row。

03 / 质量：每条输入有一个处置结果

accepted通过规则、作为有效明细和父级。
duplicate同键、全部原始字段相同的后续记录。
quarantined缺键、同键冲突、字段无效或父级/检查关联不成立。

同键任何原始字段不同，该键的所有记录都按冲突隔离；不仅隔离最后一行。无效患者或就诊导致子级隔离，任一实例无效或检查/序列元数据冲突会使整项检查隔离。reasons 可以有多个，记录处置只计一次。

影像时间超出有效就诊区间形成 warning；warning 不是第四种互斥处置，也可能属于重复或最终隔离的记录。生日按明确的 +08:00 日历日比较，事件和日汇总仍用 UTC。

如果 I-02 无效，S-01 还能当完整检查吗？

按本项目规则不能。S-01 整项隔离，S-02 若有效仍保留。否则下游会把缺少实例的检查误当作完整结果。这是规则选择，必须在 Python 与 Spark 两条路径保持一致。

04 / 九表：先分清粒度，再建立关联

模型粒度示例行数（全有效时）
dim_patient患者1
dwd_encounter就诊1
dwd_imaging_study检查2
dwd_imaging_series检查内序列2
dwd_imaging_instance实例3
bridge_study_modality检查×模态去重关系2
dws_patient_imaging_summary患者汇总1
dws_imaging_daily_modalityUTC 日×模态同日 CT、MR 共 2 组

稳定替代键连接各层，实例保留源哈希和行号。替代键属于假名化，不等于对生产医疗数据的完全匿名化认证。

05 / 汇总：两个实例只增加一次检查

P-DEMO：exam_count = 2，modality_count = 2
latest_exam_at = 两次检查的较晚时间
日×模态：CT 检查数 1；MR 检查数 1

若增加一位没有影像的有效患者，其 DIM/DWS/ADS 也必须有一行，exam_count=0，latest_exam_at=NULL。多模态检查可以进入多个日模态组，所以日分组检查数加总对齐的是桥表行数，不一定是检查去重总数。

06 / 消费：查询和交换共用成功快照

公共读取器先验证 manifest 和文件哈希，再读取旧 JSON 或 Spark Parquet 目录。数据库单事务写入并对账后切换 schema 内的 current；FHIR 从 DIM/DWD 映射 Patient、Encounter、ImagingStudy 摘要，并校验 ID、引用和落盘结果。

API 中的 exam_count=2
 → 患者汇总 → S-01 / S-02
 → I-01 / I-02 / I-03
 → source_sha256 + source_row → 原始 CSV

FHIR 检查数也是 2，实例数保留在摘要计数字段中，不为每个实例发明一个检查资源。当前不接入 observations，也不把影像摘要映射成 Observation。
