## 修改方式

编辑 `chapters/` 下对应正文片段与 `chapters.css`，再运行：

```powershell
.\.venv\Scripts\python.exe docs/html/build_chapters.py
```

生成器以自身路径定位目录，可从任意工作目录调用。不要仅修改生成后的页面，否则下一次构建会覆盖修改。新章节同时加入生成器的 CHAPTERS。
